Privacy Policy

Shorts Pipeline (My Clips Project) · Last updated: 19 November 2026 (v2)

Shorts Pipeline is a self-hosted application that runs on its operator's own computer. It is used only by its operator to upload videos to the operator's own YouTube channel. This policy explains exactly what Google and YouTube data the application accesses, how it is used and where it is stored.

1. Google user data the application accesses

When you connect a Google account, you grant the application these permissions (OAuth scopes):

  • youtube.upload (“Manage your YouTube videos”) – used only to upload new videos that you produced with the application, together with their title, description, tags, category, visibility and optional scheduled publish time.
  • youtube.readonly (“View your YouTube account”) – used only to (a) read the name of the connected channel once, so you can confirm the correct channel is connected, and (b) read the status (visibility, publish time, processing status) and public counts (views, likes, comments) of videos that the application itself uploaded.
  • yt-analytics.readonly (“View YouTube Analytics reports”) – used only to read performance figures (views, average view duration and average percentage viewed) of videos that the application itself uploaded.

The application does not read your other videos, comments, subscribers, analytics of other videos, email, contacts or any other Google data.

2. How the data is used

  • Uploading the videos you created and setting their metadata and visibility.
  • Confirming which channel is connected and verifying the visibility of uploaded videos.
  • Reading view, like and comment counts and audience-retention figures of the application's own uploads, to decide which kinds of moments to clip in the future. This analysis runs only on the operator's computer.

Google user data is not used for advertising, is not sold, and is not used to train machine-learning or AI models. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Where data is stored

  • OAuth tokens (access and refresh token) are stored in a file on the operator's own computer. They are never published, never committed to source control and never sent to anyone other than Google.
  • Upload records – the YouTube video ID, upload time, scheduled publish time and the visibility YouTube reported – are kept in a local database on the operator's computer so the same clip is never uploaded twice, together with the performance figures listed above.
  • No Google user data is sent to any server run by the developer. The application has no server, no analytics and no tracking.

4. Sharing

Google user data is shared only with Google/YouTube, as part of the API requests described above. It is not shared with, sold to or transferred to any third party.

Optional feature: if the operator enables AI-written titles, the text transcript of a clip (speech from the livestream, not Google account data) is sent to the Anthropic API to suggest a title. No Google user data or tokens are included.

5. Retention and deletion

  • Tokens remain on the operator's computer until the operator deletes the token file or revokes access.
  • Upload records and performance figures remain in the local database until the operator deletes them. Local copies of video files are deleted automatically 30 days after the video has been published.
  • You can revoke the application's access at any time at myaccount.google.com/permissions. After revocation the stored token stops working; deleting the application's folder removes all locally stored data.
  • Videos uploaded to YouTube are governed by YouTube and can be managed or deleted in YouTube Studio.

6. Security

Data is stored only on the operator's computer, protected by that computer's account and disk security. All communication with Google uses HTTPS.

7. YouTube and Google policies

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

8. Children

The application is not directed to children and is not intended for use by anyone under 18.

9. Changes and contact
